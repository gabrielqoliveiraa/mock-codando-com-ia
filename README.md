# Mock interview: Codando com IA

Treino da etapa de AI Coding. Você recebe um worker de notificações em Java que já existe e vai investigar um incidente nele.

## Pré-requisitos

- JDK 21 ou mais novo (`java -version` para conferir).
- Nenhuma dependência externa: sem Maven, sem Gradle.

## Como rodar

```bash
git clone <url-deste-repositorio>
cd <pasta-do-repositorio>
java NotificacoesQuintoAndar.java
```

Leva uns 4 segundos. Durante a execução aparece um painel de métricas a cada 500 ms, e no final um resumo com throughput, uso das threads, retries e o tempo de espera de cada fila.

## Antes da entrevista

- Confira que o comando acima roda na sua máquina.
- Deixe pronta a ferramenta de IA que você costuma usar (Cursor, Copilot, ChatGPT, Claude…), porque você vai compartilhar a tela.
- Não precisa estudar o código antes. O enunciado do incidente vai ser apresentado na hora.

Durante a entrevista, pense em voz alta.
